1 수집하는 개인정보 항목

2 개인정보 수집 목적
  • Google 계정 (이메일, 프로필): 회원 식별 및 로그인 인증 목적으로만 사용되며, 마케팅·광고 타겟팅에 활용되지 않습니다.
  • YouTube 구독 목록: 사용자가 직접 채널을 선택해 앱에 등록할 수 있도록 목록을 표시하는 용도로만 사용됩니다. 선택 완료 후 해당 데이터는 즉시 폐기됩니다.
  • 서비스 이용 기록 관리 및 부정 이용 방지
  • Google AdMob을 통한 맞춤 광고 제공

  • YouTube 구독 목록은 채널 선택 목적으로만 사용되며 서버에 영구 저장되지 않음
4 제3자 제공 및 연동 서비스

앱은 이용자의 개인정보를 외부에 판매하거나 제공하지 않습니다. 단, 아래 서비스와 기능 제공을 위해 연동됩니다.

5 Google 사용자 데이터 처리 방침

본 섹션은 Google API Services User Data Policy 및 Google APIs Terms of Service 준수를 위해 Google 사용자 데이터의 접근·사용·저장·공유 방식을 명시합니다.

접근하는 Google 데이터 범위 (OAuth Scope)

OAuth Scope 접근 데이터 사용 목적
openid, profile, email Google 계정 이메일, 프로필 이름 회원 식별 및 로그인 인증
youtube.readonly YouTube 구독 채널 목록 (읽기 전용) 채널 등록 화면에서 구독 목록 표시

데이터 사용 방식

  • Google 계정 정보(이메일, 프로필)는 회원 식별 및 로그인 인증 목적으로만 사용되며, 앱 서버(Supabase)에 저장됩니다.
  • YouTube 구독 목록은 사용자가 등록할 채널을 선택하는 화면에서만 일시적으로 사용됩니다. 선택 완료 즉시 메모리에서 삭제되며, 앱 서버에 저장되지 않습니다.
  • Google 데이터는 광고 타겟팅, 프로파일링, 제3자 제공 등의 목적으로 사용되지 않습니다.
  • 앱은 Google 데이터를 서비스 제공에 필요한 최소한의 범위로만 요청하며(최소 권한 원칙), 불필요한 데이터는 수집하지 않습니다.

데이터 저장 및 보안

  • 저장되는 Google 데이터(이메일, 프로필)는 Supabase(Northeast Asia 리전) 서버에 암호화되어 보관됩니다.
  • YouTube 구독 목록은 앱 서버에 저장되지 않으며, 네트워크 전송 시에도 HTTPS를 통해 암호화됩니다.
  • 회원 탈퇴 시 저장된 모든 Google 관련 데이터는 즉시 삭제됩니다.

데이터 공유 제한

  • Google을 통해 수집된 사용자 데이터는 제3자에게 판매, 임대, 공유되지 않습니다.
  • Google 데이터는 앱 서비스 제공 목적 이외에 사용되지 않으며, 인간이 직접 열람하지 않습니다(단, 사용자 요청 또는 법적 의무가 있는 경우 제외).
  • 본 앱은 Google API Services User Data Policy의 Limited Use 요건을 준수합니다.

접근 권한 철회

  • 사용자는 언제든지 Google 계정 설정 → 앱 권한에서 채널픽의 YouTube 데이터 접근 권한을 철회할 수 있습니다.
  • 권한 철회 시 YouTube 구독 목록 가져오기 기능은 사용할 수 없으나, 앱의 다른 기능은 정상적으로 이용 가능합니다.
6 광고 식별자 사용

앱은 Google AdMob을 통해 맞춤 광고를 제공하며, 이 과정에서 기기 광고 식별자(IDFA)가 사용될 수 있습니다.

  • iOS 설정 → 개인 정보 보호 → 추적 → 앱이 추적을 요청하도록 허용에서 변경 가능
  • 추적 거부 시에도 앱의 모든 기능을 정상적으로 이용할 수 있습니다
