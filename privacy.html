5Google 사용자 데이터 처리 방침

본 섹션은 Google API Services User Data Policy 및 Google APIs Terms of Service 준수를 위해 Google 사용자 데이터의 접근·사용·저장·공유 방식을 명시합니다.

접근하는 Google 데이터 범위 (OAuth Scope)

OAuth Scope접근 데이터사용 목적
openid, profile, emailGoogle 계정 이메일, 프로필 이름회원 식별 및 로그인 인증
youtube.readonlyYouTube 구독 채널 목록 (읽기 전용)채널 등록 화면에서 구독 목록 표시

데이터 사용 방식

  • Google 계정 정보(이메일, 프로필)는 회원 식별 및 로그인 인증 목적으로만 사용되며, 앱 서버(Supabase)에 저장됩니다.
  • YouTube 구독 목록은 사용자가 등록할 채널을 선택하는 화면에서만 일시적으로 사용됩니다. 선택 완료 즉시 메모리에서 삭제되며, 앱 서버에 저장되지 않습니다.
  • Google 데이터는 광고 타겟팅, 프로파일링, 제3자 제공 등의 목적으로 사용되지 않습니다.
  • 앱은 Google 데이터를 서비스 제공에 필요한 최소한의 범위로만 요청하며(최소 권한 원칙), 불필요한 데이터는 수집하지 않습니다.

데이터 저장 및 보안

  • 저장되는 Google 데이터(이메일, 프로필)는 Supabase(Northeast Asia 리전) 서버에 암호화되어 보관됩니다.
  • YouTube 구독 목록은 앱 서버에 저장되지 않으며, 네트워크 전송 시에도 HTTPS를 통해 암호화됩니다.
  • 회원 탈퇴 시 저장된 모든 Google 관련 데이터는 즉시 삭제됩니다.

데이터 공유 제한

  • Google을 통해 수집된 사용자 데이터는 제3자에게 판매, 임대, 공유되지 않습니다.
  • Google 데이터는 앱 서비스 제공 목적 이외에 사용되지 않으며, 인간이 직접 열람하지 않습니다(단, 사용자 요청 또는 법적 의무가 있는 경우 제외).
  • 본 앱은 Google API Services User Data Policy의 Limited Use 요건을 준수합니다.

접근 권한 철회

  • 사용자는 언제든지 Google 계정 설정 → 앱 권한에서 채널픽의 YouTube 데이터 접근 권한을 철회할 수 있습니다.
  • 권한 철회 시 YouTube 구독 목록 가져오기 기능은 사용할 수 없으나, 앱의 다른 기능은 정상적으로 이용 가능합니다.

  • 추적 거부 시에도 앱의 모든 기능을 정상적으로 이용할 수 있습니다

5Googleユーザーデータの取り扱い方針

本セクションは、Google API Services User Data PolicyおよびGoogle APIs Terms of Serviceに準拠するため、Googleユーザーデータへのアクセス・使用・保存・共有の方法を明示します。

アクセスするGoogleデータの範囲（OAuth Scope）

OAuth Scopeアクセスデータ使用目的
openid, profile, emailGoogleアカウントのメール、プロフィール名会員識別およびログイン認証
youtube.readonlyYouTubeチャンネル登録リスト（読み取り専用）チャンネル登録画面での登録リスト表示

データの使用方法

  • Googleアカウント情報（メール、プロフィール）は、会員識別およびログイン認証の目的のみに使用され、アプリサーバー（Supabase）に保存されます。
  • YouTubeチャンネル登録リストは、ユーザーが登録するチャンネルを選択する画面でのみ一時的に使用されます。選択完了後、即座にメモリから削除され、アプリサーバーには保存されません。
  • Googleデータは、広告ターゲティング、プロファイリング、第三者提供等の目的には使用されません。
  • アプリはGoogleデータをサービス提供に必要な最小限の範囲のみリクエストし（最小権限の原則）、不要なデータは収集しません。

データの保存およびセキュリティ

  • 保存されるGoogleデータ（メール、プロフィール）は、Supabase（Northeast Asiaリージョン）サーバーに暗号化されて保管されます。
  • YouTubeチャンネル登録リストはアプリサーバーに保存されず、ネットワーク転送時もHTTPSにより暗号化されます。
  • 退会時、保存されているすべてのGoogle関連データは即時削除されます。

データ共有の制限

  • Googleを通じて収集したユーザーデータは、第三者に販売、貸与、共有されません。
  • Googleデータはアプリサービス提供目的以外には使用されず、人間が直接閲覧することはありません（ただし、ユーザーの要求または法的義務がある場合を除く）。
  • 本アプリはGoogle API Services User Data PolicyのLimited Use要件に準拠しています。

アクセス権限の撤回

  • ユーザーはいつでもGoogleアカウント設定 → アプリの権限から、チャンネルピックのYouTubeデータアクセス権限を撤回できます。
  • 権限撤回後、YouTubeチャンネル登録リストの取得機能は使用できなくなりますが、アプリの他の機能は正常にご利用いただけます。
6広告識別子の使用

アプリはGoogle AdMobを通じてパーソナライズ広告を提供しており、この過程で端末の広告識別子（IDFA）が使用される場合があります。

  • iOSの設定 → プライバシーとセキュリティ → トラッキング → アプリのトラッキング要求を許可で変更可能
  • トラッキングを拒否した場合でも、アプリのすべての機能を正常にご利用いただけます
